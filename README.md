# kohi-cafeteria-demo

Proyecto demo en local para probar **servidores MCP** y sistemas de agentes.

El objetivo no es la aplicación en sí, sino usarla como excusa para encadenar
varios MCP de principio a fin: diseñar un esquema de base de datos, implementar
contra él, verificarlo en un navegador real y publicar el resultado para
revisión — todo a través de servidores MCP.
